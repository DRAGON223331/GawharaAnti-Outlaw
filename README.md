# GawharaAnti-outlaw 1.1.0

Plugin حماية وإشراف لسيرفر Minecraft Java المبني على Paper.

## المميزات

### الشات
- فلتر شتائم يفهم العربي: يتجاهل التشكيل والتطويل، ويوحّد (أ إ آ ا) و(ى ي) و(ة ه)، ويكشف الحروف المكررة ("شتتتيمة")، والمسافات والرموز بين الحروف، والأرقام بدل الحروف (leetspeak).
- قائمة `whole-word-words` للكلمات القصيرة اللي لازم تتطابق ككلمة كاملة بس.
- حظر الروابط: `http(s)://` و`www.` والدومينات بدون بروتوكول (`evil.com`) والمموهة (`evil (dot) com`) ودعوات ديسكورد.
- سبب الحظر بيتسجل بالتفصيل: الدومين غير مسموح / امتداد الملف غير مسموح / دعوة ديسكورد / دومين بحروف مشابهة.

### الديسكورد
كل تنبيه بيتبعت كـ Embed ملوّن، وفيه **النص الكامل للرسالة أو الرابط الممنوع**، واسم اللاعب والـ UUID والموقع والـ Ping ورقم المخالفة.
- طابور إرسال بيتعامل مع حد الـ Rate Limit (429) بنفسه.
- ما بيتم عمل Mention لأي حد (`allowed_mentions` فاضية).
- رسالة الإيقاف بتتبعت فعلاً قبل ما السيرفر يقفل.

### كشف الـ X-Ray
1. **الخامات المخفية مقابل الظاهرة:** الخامة اللي كانت ظاهرة في كهف أو نفق قديم **مش** بتتحسب كشك. الخامة اللي كانت مدفونة ووصلها اللاعب بنفقه هي بس اللي بتتحسب "مخفية".
2. **نافذة زمنية متحركة** (افتراضياً 10 دقايق) بدل العد الدائم.
3. **درجة شك من 0 لـ 100** مع أسباب مكتوبة، وثلاث مستويات: LOW / MEDIUM / HIGH. التنبيه بيتبعت مرة تانية لما المستوى يزيد.
4. القياسات: نسبة الخامات المخفية، خامات مخفية في الدقيقة، متوسط البلوكات بين كل خامتين، عدد مرات تغيير اتجاه النفق مباشرة ناحية خامة.
5. تتجاهل البلوكات اللي اللاعب حطها بنفسه، واللاعبين في غير وضع Survival.
6. **صورة دليل (PNG)** بيرسمها السيرفر: مسار الحفر من فوق ومن الجنب، الخامات المخفية والظاهرة، وأماكن الخامات الوهمية. بتتبعت مع التنبيه في ديسكورد.
7. رسالة للأدمن في اللعبة فيها زر `[TP]`.

### فخ الخامات الوهمية (Decoys)
لما لاعب يبقى مشتبه فيه، السيرفر بيعرض له **على جهازه هو بس** بلوكات ستون مدفونة على إنها خامات غنية (ألماس، زمرد، ...). العالم الحقيقي مش بيتغير أبداً: كله ستون.
- اللاعب العادي مش بيشوف بلوكات مدفونة، فمفيش أي تأثير عليه.
- لاعب بـ X-Ray هيشوف خامات في كل حتة وهيحفر ناحيتها.
- لما نفقه يوصل لخامة وهمية، بتتحول للستون الحقيقي، وبتتسجل كدليل. الحفر ناحية عدد كبير منها أكتر من الصدفة = دليل قوي.
- الأوضاع: `OFF` / `SUSPECTS` (الافتراضي) / `ALL` من `xray-monitor.decoys.mode`.

### الـ Client Brand
بيقرأ الاسم المعلن من العميل بشكل صحيح (VarInt) ويبعت تنبيه فيه الاسم والكلمة المطابقة والـ Ping والـ plugin channels المسجلة. ده مؤشر مش إثبات، ومفيش عقوبة تلقائية.

## حدود مهمة (اقرأها)

- **مفيش Plugin يقدر يصوّر شاشة لاعب.** الـ X-Ray بيتعرض جوه جهاز اللاعب نفسه، والسيرفر مبيشوفه. لذلك الصورة في ديسكورد هي **إعادة بناء** من بيانات السيرفر، مش لقطة شاشة.
- كل كشف إحصائي ممكن يغلط. الدرجة والصورة للمراجعة، **مش حكم نهائي**. ما تستخدمهاش وحدها للحظر.
- الصورة بتحتاج وحدة `java.desktop` في الـ JRE. لو مش موجودة، التنبيه بيتبعت نصاً بدون صورة.
- الخامات اللي لاعب حطها قبل إعادة تشغيل السيرفر مش بتتتبع (الذاكرة بتتصفّر).
- رقم Discord Channel ID مش رابط Webhook. أنشئ Webhook للروم وحط رابطه في `discord.webhook-url`.

## ضبط Paper Anti-Xray (مهم جداً، بيحمي الكل)

الـ Plugin ده بيكشف. الحماية الحقيقية من الـ X-Ray للجميع تتفعّل من Paper نفسه. افتح `config/paper-world-defaults.yml` (أو إعداد العالم) وراجع وثائق إصدار Paper عندك:

```yaml
anticheat:
  anti-xray:
    enabled: true
    engine-mode: 2        # 1 = تخفي الخامات بستون، 2 = تحط خامات وهمية عشوائية (يشوفها الغشاش بس)
    max-block-height: 64
    update-radius: 2
    lava-obscures: false
    use-permission: false
```

`engine-mode: 2` بيحقق نفس فكرة "خامات في كل حتة وكلها ستون" لكل اللاعبين، وده أقوى وأخف من الفخ. الفخ في الـ Plugin بيضيف **تسجيل الدليل** للمشتبه فيهم.

## البناء من GitHub

1. أنشئ Repository جديداً باسم `GawharaAnti-outlaw`.
2. ارفع محتويات هذا المشروع إلى جذر الـ Repository، بحيث يكون مجلد `.github` ظاهراً.
3. افتح تبويب **Actions** وانتظر انتهاء `Build GawharaAnti-outlaw`.
4. نزّل Artifact باسم `GawharaAnti-outlaw`، فك الضغط، وضع ملف `.jar` في مجلد `plugins`، ثم أعد تشغيل السيرفر.

محلياً (JDK 25 وMaven):
```bash
mvn clean package
```

## إعداد Discord

1. من إعدادات الروم: Integrations ثم Webhooks، أنشئ Webhook وانسخ العنوان.
2. بعد تشغيل السيرفر مرة، افتح `plugins/GawharaAnti-outlaw/config.yml` وحط الرابط في `discord.webhook-url`.
3. نفّذ `/gao reload` ثم `/gao test` للتأكد.

**أمان:** لا ترفع رابط Webhook إلى GitHub ولا ترسله في محادثة عامة. لو اتسرّب، احذفه وأنشئ واحد جديد.

## الأوامر والصلاحيات

| الأمر | الوظيفة |
|---|---|
| `/gao status` | حالة الـ Plugin والـ Discord والـ X-Ray |
| `/gao reload` | إعادة قراءة الإعدادات |
| `/gao test` | رسالة اختبار في ديسكورد |
| `/gao xray <player>` | درجة الشك والأسباب والإحصائيات داخل اللعبة |
| `/gao evidence <player>` | إرسال تقرير + صورة دليل فوراً لديسكورد |
| `/gao exempt add\|remove\|list <player>` | استثناء دائم (بيتحفظ في `exemptions.yml`) |

- `gawharaoutlaw.admin` (افتراضياً OP): الأوامر واستقبال التنبيهات.
- `gawharaoutlaw.bypass` (افتراضياً لا أحد): تجاوز الفلاتر والمراقبة.
